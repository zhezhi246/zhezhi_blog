这是「[未来规划：从 C++ 到推理部署的十三个月](../future-plan-2026-2027/)」里 C++ 阶段的课程细化。结论先说：**learncpp 不要从 0 通读到 28**。按部署岗面试考点，读约 45% 就够。课程地址：[learncpp.com](https://www.learncpp.com/)。

## 必学主线

`0-2 → 4-8 → 10 → 12 → 13-17 → 18.2-18.3 → 19.1-19.3 → 20.2/20.3/20.6-20.7 → 22 → 24-25`

其中 12（引用/指针）、14-15（类/RAII）、16（vector）、22（移动语义/智能指针）、24-25（继承/虚函数）是重点；26（模板与类）、28（I/O）和大量细节可以直接跳过。

## learncpp 覆盖不到的部分

**最大的空白是 STL 容器与 `unordered_map`。** learncpp 只讲了 `std::vector`、`std::array`、迭代器和少量算法，**没有 `unordered_map`、`map`、`set`、`list`、`deque`、`priority_queue`，也没有哈希表底层**。计划里明确要求的 `unordered_map` 底层，需要这样补：

- cppreference：查 API、复杂度、迭代器失效规则；
- 牛客/八股：buckets、链地址法、load factor、rehash、平均 O(1) 与最坏 O(n)；
- 手写一遍 LRU（`unordered_map` + `list`），正好对应 LeetCode 计划里的必会题；
- `std::sort` / `std::stable_sort` / `priority_queue` 的用法和复杂度。

另外几个边界：

- **内存模型**：learncpp 讲的是对象大小、存储期、链接性、栈/堆、动态分配，不讲 `std::atomic` 的 memory order。部署岗面试通常够用，真被问到并发内存模型再补。
- **RAII**：learncpp 没有单独一章。重点看 15.4（析构）、19.3（动态分配的析构）、22.5-22.7（智能指针），配合 27.3 的 stack unwinding。
- **模板**：区分「会用模板」和「模板元编程」。11.6-11.10、26.1 会读会写简单模板即可；26.2-26.6 的偏特化、SFINAE、TMP 直接跳过。
- **设计模式 / Boost**：learncpp 没有设计模式章节，单例和工厂另外看；Boost 完全不碰。

## 和 Phase 1 验收标准对应

| 验收点 | learncpp 章节 | 还要补 |
| --- | --- | --- |
| 哈希 + 排序题 | 16.10、18.3 | `unordered_map` / `sort` 的 API 与底层 |
| 智能指针 | 22.5-22.7 | `make_shared`、控制块、循环引用、引用计数线程安全 |
| 虚函数表 | 25.1-25.7，重点 25.6 | vptr/vtable、虚析构、对象切片 |
| vector 扩容 | 16.10 | 1.5x/2x 增长、reserve、迭代器失效 |

## 按 Phase 1 的 5 周排

| 周 | 内容 |
| --- | --- |
| 第 1 周 | 0-2、4-6 |
| 第 2 周 | 7-8、10、12 |
| 第 3 周 | 13-15、16-17 |
| 第 4 周 | 18-20、22 |
| 第 5 周 | 24-25、21.12-21.13、27 选读 + STL 补漏 |

每天 learncpp 2-3 小时 + LeetCode 2-3 小时；**只做章末 quiz，不刷每节习题**。落后时优先保 **12、14-16、22、24-25**，其余章节直接用牛客八股查漏。

## 使用方式

- learncpp 是文字教程，不是视频。视频课可以当快速预习，learncpp 用来补细节和做章末 quiz，不要两个都从头刷。
- 只做章末 quiz，不刷每节习题；代码练习直接交给 LeetCode。
- 每读完一个必学章节，用一句话回答「这章面试会问什么」，答不上来就回看。
- 这份指南会随学习进度更新。
