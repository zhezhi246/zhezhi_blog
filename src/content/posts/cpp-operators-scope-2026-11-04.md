今天的内容从表达式一路延伸到多文件程序。前半部分关心“表达式怎样计算”，后半部分关心“名字在哪里可见，对象能存在多久，定义怎样连接起来”。

## 一、今天学到的知识点

### 1. 除法、余数与宽度补齐

整数除法向零截断，`7 / 3` 是 2，`-7 / 3` 是 -2；余数与被除数同号或为零，所以 `-7 % 3` 是 -1。

```cpp
int width{641};
int stride{32};
int padding{(stride - width % stride) % stride}; // 31
bool odd{width % 2 != 0};
```

补齐公式用于这里的非负宽度和正步长，已经整除时补齐量为零。内置 `%` 不支持浮点数，浮点余数可查 `<cmath>` 的 `std::fmod`。`^` 表示按位异或，`2 ^ 3` 是 1；幂运算可使用 `std::pow`，但需考虑浮点舍入。

### 2. 自增、自减与副作用

| 表达式 | 变量变化 | 表达式使用的值 |
| --- | --- | --- |
| `++x` | 加一 | 新值 |
| `x++` | 加一 | 旧值 |
| `--x` | 减一 | 新值 |
| `x--` | 减一 | 旧值 |

修改变量、写入输出流都属于副作用。副作用本身正常，但应避免把多个相关修改挤在一个表达式里。

```cpp
int x{5};
// int y{x++ + x++}; // 不要执行：两次修改没有顺序保证，属于未定义行为
int previous{x++};  // previous 为 5，x 为 6
```

逗号运算符会先算左侧，再算右侧，并以右侧作为结果，例如 `int z{(++x, ++y)};`。日常代码拆成语句通常更清楚；函数实参之间的分隔逗号不等于逗号运算符。

### 3. 条件运算与浮点比较

Python 的 `a if a > b else b`，在 C++ 中可写为 `(a > b) ? a : b`。

浮点计算常产生近似值，比较计算结果时应依据数值尺度和误差需求选择容差：

```cpp
#include <cmath>

bool approximatelyEqual(double a, double b)
{
    return std::abs(a - b) < 1e-12;
}
```

这是适用于本例尺度的绝对容差示例，不是适用于所有数量级的通用比较器。

### 4. 逻辑运算、短路与德摩根定律

| C++ | Python | 含义 |
| --- | --- | --- |
| `&&` | `and` | 与 |
| `||` | `or` | 或 |
| `!` | `not` | 非 |

内置 `&&` 左侧为假时不计算右侧；内置 `||` 左侧为真时不计算右侧。

```cpp
int x{0};
int y{5};
bool result{(x != 0) && (y / x > 2)}; // 右侧不执行，没有除零
bool inRange{(-10 < x) && (x < 0)};
```

`-10 < x < 0` 会按 `(-10 < x) < 0` 计算，不能表达数学里的区间比较。`&&` 的优先级高于 `||`，混合条件用括号表达意图。

德摩根定律：`!(a && b)` 等价于 `!a || !b`；`!(a || b)` 等价于 `!a && !b`。

### 5. 局部变量、遮蔽与按值参数

```cpp
int x{10};
{
    int x{20};
    std::cout << x << '\n'; // 20
}
std::cout << x << '\n';     // 10
```

内部声明的是另一个对象，遮蔽了外层名字。离开内层代码块后，外层对象仍在。

```cpp
void process(int local)
{
    ++local;
    std::cout << local << '\n';
}
// 外部 count 为 0 时，连续 process(count) 三次，分别输出 1。
```

按值参数可以理解成：新建一个局部对象，用实参的值初始化，再修改这个局部对象。没有修改调用者的 `count`。

### 6. 全局状态、内部链接与外部链接

函数外的普通全局变量具有静态存储期，能跨函数调用保留状态。对同一个全局计数器累加三次，结果是 3；但隐藏的全局状态会增加理解和调试难度。

普通命名空间作用域函数默认具有外部链接，可以通过声明在其他翻译单元引用它。只在当前文件使用的辅助函数可放进匿名命名空间：

```cpp
namespace
{
    int normalizeBatchSize(int size)
    {
        return size > 0 ? size : 1;
    }
}
```

在命名空间作用域给函数加 `static` 也能获得内部链接。

### 7. 编译、链接、运行

在已安装 GCC 的 Linux 或 WSL 中：

```bash
g++ -std=c++17 main.cpp calc.cpp -o app
./app
```

编译阶段分别处理源文件，链接阶段把目标文件和库中的引用与定义连接起来，最后才运行程序。只编译调用方而漏掉提供函数定义的 `calc.cpp`，可能在链接时出现未定义引用。

## 二、我的心得与注意事项

- **判断奇数用 `n % 2 != 0`，不要用 `n % 2 == 1`，因为负奇数的余数可能为 -1。**
- **`^` 不是乘方；浮点余数也不能直接写 `%`。**
- **前置自增先改再用，后置自增取旧值；不需要旧值时优先写 `++x`。**
- **副作用不等于错误，但多个相关修改应拆开写。**
- **Python 的链式比较不能直接搬到 C++；区间条件用两个比较加 `&&`。**
- **按值传参记成“新建局部副本”，更容易理解为什么外面的值没有变。**
- **尽量减少隐藏状态，让函数的行为更容易预测。**
- **多文件命令中要包含提供定义的 `.cpp`；头文件通常通过 include 进入翻译单元，不单独列入编译命令。**

## 三、整理时补充的边界

**作用域回答名字在哪里可见，生命周期回答对象何时存在，链接属性回答不同位置的名字能否指向同一实体。** 这三个问题需要分开判断。
