## Phase 1｜2026.10 – 11：C++ 从 0 到 1，LeetCode 同步启动

### 学习路线

不通读《C++ Primer》。以 [learncpp](https://www.learncpp.com/) 为主干，配一套视频课 2 倍速过一遍作辅助，再用牛客的 C++ 面试八股帖当索引查漏。范围按部署岗的面试考点收窄：

- 基础语法，重点是引用与指针；
- 内存模型；
- 类与 RAII，智能指针（`unique_ptr` / `shared_ptr` / `weak_ptr` 必考）；
- STL 常用容器，以及 `unordered_map` 的底层实现；
- 虚函数与多态；
- 移动语义（先到概念级）；
- `lambda`、`auto` 这类现代特性。

明确不学：模板元编程、Boost、设计模式全集。设计模式只看单例和工厂。

### 关键动作

直接用 C++ 刷 LeetCode。前 50 题会非常痛苦，60 题之后手感基本就形成了——这是练 C++ 语法最快的办法，也顺手把算法题刷了，一箭双雕。具体刷法见下文「LeetCode 怎么刷」。

### 验收标准

- 能用 C++ 独立写出哈希、排序级别的题；
- 能给别人讲清楚智能指针、虚函数表、`vector` 扩容机制。

## Phase 2｜2026.12：CUDA 入门 + LLM 上手

三件事平分时间：CUDA、LLM、LeetCode 继续。

### CUDA

读《Programming Massively Parallel Processors》前几章，或跟 UIUC ECE408 公开课。目标是亲手写出三个 kernel：

1. 向量加法；
2. 归约（reduction）；
3. 手写 softmax（面试高频）。

同时理解 threads / blocks / warp 的层级，global memory 与 shared memory 的区别，以及访存合并（coalescing）。

### LLM：从“懂架构”到“用过”

- 本地用 ollama 跑一个 Qwen，或者直接玩 API；
- 精读 LLaMA 论文，搞清它和原始 Transformer 的五处差异：pre-Norm、RMSNorm、SwiGLU、RoPE、GQA；
- 用 HuggingFace TRL 跑一次 demo 级 SFT；
- 装一次 vLLM 起服务，压一下延迟。

这一步同时覆盖了 LLM 算法岗面试的基础盘。

### 验收标准

- 能白板讲清 CUDA softmax 的并行思路；
- 能说清 KV Cache 和 MQA/GQA 各自省在哪里。

## Phase 3｜2027.01（寒假）：旗舰项目

这是简历的核心：一个项目，撑起两个赛道的面试。

```
YOLOv8 → 导出 ONNX → TensorRT FP16 → INT8 量化（PTQ：MinMax / KL 校准）→ 部署 → benchmark
```

### 产出物

- 一个 GitHub 仓库；
- README 里放一张 FP32 / FP16 / INT8 的延迟、吞吐、mAP 损失对比表；
- 外加踩坑记录。

### 有余力再加两项

- 手写一个预处理融合 CUDA kernel（letterbox + HWC→CHW + 归一化），替代 OpenCV 调用；
- 写一个简单的 TensorRT plugin。

### 硬件

实验室 GPU 跑 x86 TensorRT 就够。预算宽裕（3000 左右）可以买一块 Jetson Orin Nano——“真机部署”四个字在简历上更值钱，但不是必需。

### 同月完成

写好简历 v1，找师兄或网上帮忙 review。

### 验收标准

这个项目能在面试里撑起 20 分钟，每个数字都经得起追问：为什么 INT8 掉了 1.2 个点？校准集怎么选的？

## Phase 4｜2027.02 中 – 05：投递 + 面试

2 月中旬开始投暑期实习，目标池：

- 大厂 AI Infra / 推理优化岗；
- 智驾：理想、小米汽车、华为车 BU、地平线、美团无人车、法雷奥；
- 机器人：宇树、智元、优必选；
- AI 独角兽。

### 2 月：八股冲刺

- 量化原理：我的主场，可以从数值分析讲起；
- Transformer 细节：为什么除以 $\sqrt{d}$、KV Cache、GQA；
- 操作系统基础：进程 / 线程、内存管理；
- 网络基础：TCP / HTTP 够用；
- C++ 八股回炉。

每次面试后复盘，迭代简历。

## LeetCode 怎么刷

主线路径，按顺序走，不要乱刷。

### 第一轮｜2026.11 – 12 月中：Hot 100，按专题刷

打开 leetcode.cn 的「热题 100」官方学习计划，但不按顺序刷，按专题分组：

哈希 → 双指针 → 滑动窗口 → 二分 → 链表 → 栈与队列 → 二叉树（DFS / BFS）→ 回溯 → DP 基础 → 贪心 → 堆。

同一个专题连做 8–10 题，模式感形成得最快。

### 第二轮｜2026.12 中 – 2027.02：CodeTop 高频

[codetop.cn](https://codetop.cn) 把各大公司的真实面试题按出现频率排序，是校招事实上的标准工具。

用法：筛「字节」「腾讯」「美团」的高频前 100–150 题。目标公司就这几类，重合度很高，实际增量大约 100 题。面试前一周，只复盘 CodeTop 上目标公司的高频题 + 自己的错题本。

### 单题习惯

- 一道题想 15–20 分钟没思路，就看题解；
- 看懂后关掉题解，自己默写一遍；
- 三天后重做。

### 难度取舍

以 medium 为主——面试 90% 是 medium。hard 只需要会几道超高频的：接雨水、滑动窗口最大值。另外，LRU 缓存虽然是 medium，但必会：用 C++ 的 `unordered_map` + `list` 手写，刚好也是 C++ 功底练习。
